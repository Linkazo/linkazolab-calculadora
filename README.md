# Calculadora Linkazo Lab

Calculadora de precios de impresión 3D de Linkazo Lab. La página está cifrada: hace falta la contraseña para abrirla.

Los datos (ajustes y presupuestos) se guardan solo en el navegador de cada dispositivo. Usa *Ajustes → Copia de seguridad* para exportarlos e importarlos en otro aparato.
