# Calculadora Linkazo Lab

Calculadora de precios de impresión 3D de Linkazo Lab. La página está cifrada: hace falta la contraseña para abrirla.

- Datos: en el navegador de cada dispositivo y, si se conecta un token en *Ajustes → Guardar en GitHub*, en un repositorio privado aparte.
- *Ajustes → Copia de seguridad* exporta e importa todo en un archivo.
